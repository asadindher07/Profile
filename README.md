# Asad Indher — Portfolio Website

A single-file, no-build portfolio (`index.html`) built from the resume. Works on any static host.

## Deploy to Vercel for free (no coding needed)

**Option A — drag and drop (easiest):**
1. Go to https://vercel.com and sign up (free) with GitHub, GitLab, or email.
2. Click **Add New → Project**.
3. Choose **Deploy without Git** / look for the drag-and-drop upload box on the "Import Project" screen.
4. Drag the `index.html` file (and this folder) into the box.
5. Click **Deploy**. Vercel gives you a free `.vercel.app` link in under a minute.

**Option B — with GitHub (better for future edits):**
1. Create a new repository on https://github.com and upload `index.html`.
2. Go to https://vercel.com → **Add New → Project** → **Import Git Repository**.
3. Select your repo. Framework preset: **Other** (it's a static file, no build step needed).
4. Click **Deploy**.
5. Any time you edit `index.html` in GitHub, Vercel redeploys automatically.

## Editing your info later
Everything is in one file, `index.html`. Search for your name, email, or a job title to find the section and edit the text directly — no build tools required.

## Custom domain (optional, still free)
In the Vercel project → **Settings → Domains**, you can add a domain you own, or keep the free `yourproject.vercel.app` link.
